The Elastic Certified SIEM Analyst exam is designed for cybersecurity-focused IT professionals who have experience using the Elastic Security solution.

The Elastic Certified SIEM Analyst exam tests your knowledge and skills on using the Elastic Security solution from Stack Architecture, examining the application and guidelines of Elastic Common Schema (ECS), customizing the Discover interface to search for data, creating aggregation-based visualizations, constructing Lens visualizations for security use cases, constructing and using dashboards for security use cases, utilizing, analyzing, correlating, tracking and monitoring the security application.
